# End-to-End-Enterprise-Logistics-Real-Time-Fleet-Analytics-Platform
Microsoft Fabric Lambda Architecture platform. Integrates Dataflow Gen2 and PySpark pipelines for batch supply chain engineering, with low-latency Eventstreams and Eventhouses (KQL) for real-time fleet telemetry analytics and time-series charts. Includes advanced enterprise T-SQL warehouse security (RLS &amp; DDM).
